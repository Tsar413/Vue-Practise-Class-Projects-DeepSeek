# 教学流程与 AI 辅导交付验收（2026-10-09）

本轮基于 `58ee7fe394de009ae31e0cd67025dbeacdbebb48` 开发，新增教学任务、成果版本、人工评价和 DeepSeek 辅导。没有重写历史，没有修改原参考仓库，没有增加自动评分、查重、排行榜或学生代码执行能力。

## 开发来源与范围

- **DeepSeek Harness**：沿用原安装与模型，完成新增后端、迁移执行器、权限、前端页面、样式、单元测试及功能文档；AI 模块由 Harness 内部执行方实现后汇总。
- **Codex**：操作虚拟机环境、创建备份与隔离库、审查并反馈缺陷、独立 HTTP/浏览器验收、真实模型联调、正常库增量迁移、忽略的本地启动包装配置、此验收文档及提交上传。本轮未直接修改业务实现源代码。
- **人工参与**：用户给出业务要求、提供独立辅导凭据；此前教师验收过旧报修上传、建单与查询。本轮测试中的账号、任务、分数与评语均为隔离库的虚构验收样例，不是实际学生评价。

## 已交付的操作流程

教师进入「实训任务」新建任务，设置项目、多个班级、教学目标、要求、验收标准、参考链接、截止时间、满分和逾期规则。保存为草稿后发布。学生进入「我的任务」，保存成果草稿或正式提交链接、说明、解决过程及截图。教师在任务详情按班级查看提交，打开学生历史版本，给分或退回。学生查看对应版本反馈，修改后再次提交；旧版本、截图和评价保留。

学生可从导航、任务详情或接口文档进入「AI 实训辅导」，选择项目和可见任务，输入问题、代码、报错。回答展示后端检索到的实际来源；支持多轮、新建、切换及删除本人会话。教师不能读取学生私聊。页面不执行学生代码，模型没有 shell、数据库或代提交工具。

页面包括教师任务列表、任务编辑、提交详情与评价，以及学生任务列表、成果编辑与历史、AI 会话。任务目标、任务要求和模型回答均经清洗后展示；截图走授权接口，不使用报修附件表或目录。

## 失败、审查发现及修复记录

| 发现 | 修复与复核 |
| --- | --- |
| SQL 曾硬编码正常库；迁移锁随短连接释放；空校验和与自动删表回滚不安全 | 应用前由 Harness 改为显式校验目标库、持有文件锁、成功后记校验和、失败保留结构；未执行不安全版本 |
| 迁移记录表缺失导致重复执行识别失败 | 执行器负责创建记录表；隔离库重复执行与首次时间不变已通过 |
| 第一次真实启动的 TINYINT/INTEGER 映射不匹配 | 修正新增实体列映射；保持严格 Hibernate `validate`，后续启动通过 |
| 同类事务自调用、RR 旧快照、提交后复用事务连接、草稿 null 字段未清空 | 显式事务、READ_COMMITTED、独立提交后事务、显式置 null；真实 MySQL 并发与草稿刷新通过 |
| 历史截图单归属、临时清理缺少消费者/竞争保护 | 不可变版本关联、统一任务锁、持久删除队列与真实磁盘删除；历史截图及重置保护通过 |
| 第一轮磁盘删除断言失败，期间并行编译触发 DevTools 热重启且短暂缺少 Mapper | 停止 Harness 内部后台构建、禁用测试热重启，以稳定构建重跑；保留失败记录，原磁盘断言未削弱，重测通过 |
| 带引号凭据脱敏遗漏；文档缺请求体信息；引用可能超出实际上下文 | 补脱敏、结构摘要和预算一致性；虚构哨兵与真实文档单测/协议捕获通过 |
| AI 重复调用、删除后旧实体可能复活、无全局并发上限 | 进程内有界幂等缓存、状态重验、限流与全局许可；异常及在途删除实测通过 |
| 新接口 201 被旧前端响应处理拒绝，AI 客户端超时小于后端 | 新模块支持 200/201，AI 单独 90 秒超时；浏览器完整流程通过 |
| AI 任务选择器漏导入并吞掉异常，详情漏教学目标 | 补导入、显式加载错误与重试、目标展示；浏览器选中实际任务并调用成功 |
| 切换项目沿用旧会话、原生确认框阻塞嵌入浏览器、新建防重复不足 | 切换进入新会话草稿，旧会话保留；取消阻塞框，补在途守卫；最终浏览器复测通过 |
| 文档辅导链接引用未定义的项目变量 | Harness 补充项目计算值；浏览器验证 TICKET/REPAIR 链接及报修选中状态，最终生产构建通过 |

## 本机启动与配置

本机已有环境使用忽略的启动包装脚本，加载现有本地数据库/CORS配置和用户填写的独立 `.runtime/ai-tutor.env`。它保留 `validate`，关闭开发热重启，教学图片使用独立 `backend/teaching-files`。

```bash
cd ~/projects/Vue-Practise-Class-Projects-DeepSeek
bash .runtime/run-local.sh start
bash .runtime/run-local.sh stop
```

停止只针对本项目记录并核实身份的进程；共用且原已运行的 MySQL/Harness 保留。首次在其他机器准备环境时遵循 [运行手册](05-environment-and-runbook.md)，本机包装脚本及凭据不随仓库分发。

辅导配置变量：`AI_TUTOR_BASE_URL`、`AI_TUTOR_MODEL`、`AI_TUTOR_API_KEY`、`AI_TUTOR_TIMEOUT_SECONDS`、`AI_TUTOR_MAX_CONTEXT_CHARS`，以及 [模块说明](08-teaching-and-ai-tutor.md) 的限制参数。Key 只用于后端代理，未读取或复制 Harness/Codex 的密钥；实际 Key 在待提交源文件及前端产物中扫描未发现；启动脚本还会剔除前端进程的 AI/数据库口令环境变量，正常重启后已核对。

虚拟机本机访问 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:8100`，Harness `http://127.0.0.1:3080`。宿主机可尝试 `http://<当前虚拟机IP>:5173`；本机前端 API 地址与 CORS 已支持当前虚拟机网卡并保留 localhost，机器专属配置不提交。

## 边界与未验证项

- AI 请求幂等缓存及最小间隔为单进程保证，重启/多实例间不共享；每日限额通过数据库消息计数。同键在途请求及成功结果会复用，失败后会释放幂等键；模型超时后的重试可能再次调用供应商，不能保证前一次未计费，界面提示先查看会话记录。上下文采用现有文档关键词检索，未增加向量库。
- 脱敏覆盖常见凭据/访问码等模式，不能识别任意自由文本中的全部敏感语义；界面仍提示不要粘贴凭据。模型回答须由学生自行理解并验证，不代表已执行代码或测试。
- 未做生产部署、班级规模压力测试、上游长期可用性测试。宿主机浏览器实际连通性未操作验证，因为用户要求全部操作限定在虚拟机。
- 未重复全面验收旧业务；只回归受影响的登录/权限、两个项目查询与隔离测试重置。没有改变原五分钟前端重置冷却规则。
- 所有操作文件与进程位于当前虚拟机，未操作宿主机系统、共享目录或宿主机服务。
